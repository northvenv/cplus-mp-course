Полиморфизм - объекты с одинаковым интерфейсом имеют разную реализацию
Динамический полиморфизм - через виртуальные функции

Виртуальные функции - основа полиморфизма
Определяются во время выполнения программы

Чисто виртуальная функция - функция без реализации
virtual void show() const = 0 - делает класс абстрактным

Абстрактный класс - класс с чисто виртуальной функцией
class Personality { virtual void show() const = 0; } - абстрактный класс
Personality p - ошибка, нельзя создать объект
Можно только указатели и ссылки

Переопределение (override) - реализация чисто виртуальной функции в потомке
void show() const override - реализация в Artist и Writer

Таблица виртуальных функций (vtable) - механизм реализации
Каждый объект содержит указатель на таблицу адресов

Позднее связывание - разрешение вызова во время выполнения
В отличие от раннего связывания (во время компиляции)
Personality* p = new Artist()
p->show() - вызывает Artist::show()

В main:
Personality* arr[4]
arr[0] = new Artist(...)
arr[1] = new Writer(...)
for (int i = 0; i < 4; i++) arr[i]->show() - полиморфный вызов
