Область видимости - на протяжении всей работы программы
Существуют до создания и после удаления объектов

Статические члены - принадлежат классу, а не объектам
Статическая переменная - одна переменная на весь класс
static int objectCount - статическая переменная в Personality

Статическое поле - общая переменная для всех объектов
Инициализируется вне класса
int Personality::objectCount = 0 - инициализация вне класса

Статический метод - можно вызывать без создания объекта
Не имеет доступа к нестатическим членам
Не имеет указателя this
static int getObjectCount() { return objectCount; }
Personality::getObjectCount() - вызов

Счетчик объектов - типичное применение статических полей
Увеличивается в конструкторе
Уменьшается в деструкторе
static int arrayCount - счетчик объектов в массивах
arrayCount++ - увеличение в addPersonality()
arrayCount -= count - уменьшение в деструкторе

Изменение в конструкторах/деструкторах:
Personality() { objectCount++; } - увеличение при создании
~Personality() { objectCount--; } - уменьшение при удалении

Демонстрация:
cout << Personality::getObjectCount() - вывод количества
Artist* a1 = new Artist(...) - создание объекта
cout << Personality::getObjectCount() - обновленное количество
enc1.addPersonality(a1) - добавление в массив
cout << Encyclopedia::getArrayCount() - количество в массивах
