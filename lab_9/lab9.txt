Наследование - создание нового класса на основе существующего
пример - class Writer : public Personality

Базовый класс (родитель) - класс, от которого наследуются поля и методы

Производный класс (потомок) - класс, который наследует все от родительского класса,
добавляет новые поля и методы, а также может переопределять унаследованные методы

Модификатор protected - доступ в классе и наследниках (промежуточный между private и public)
protected: string name - поле доступно в Personality, Artist, Writer

Добавление новых полей в наследниках:
class Artist : public Personality { private: string style; } - Artist добавляет style
class Writer : public Personality { private: string mainWork; } - Writer добавляет mainWork

Виртуальные методы - методы, которые можно переопределить в дочерних классах
virtual void show() const - виртуальный метод в базовом классе

Переопределение методов - изменение реализации в потомке
void show() const override - переопределение в наследнике

Полиморфизм через указатели - использование объектов потомков через указатели на родителя
Personality* arr[3] - массив указателей на базовый класс
arr[1] = new Artist("Айвазовский", 1817, "Моренист", "Романтизм") - сохранение объекта наследника
